# 1. 프로젝트 개요
### 1.1 프로젝트 이름
- 문자열 덧셈 계산기
### 1.2 프로젝트 설명
- 입력된 문자열에서 숫자만 추출해서 더하는 계산기
---
# 2. 구현할 기능
### 2.1 입력 문구 출력 기능
- `덧셈할 문자열을 입력해 주세요.`라는 안내 문구를 출력한다.
### 2.2 문자열 입력 기능
- `camp.nextstep.edu.missionutils.Console`의 `readLine()`을 활용하여 string 값을 입력 받는다.
- 잘못된 값을 입력한 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션을 종료한다.
#### 2.2.1 입력값 유효성 검사 기능
- 기본 구분자 : 쉼표(,) 또는 콜론(:)
- 커스텀 구분자 : //문자\n 여기서 문자가 커스텀 구분자 (예 : //;\n 일때 커스텀 구분자는 ;)
- 예외 발생
  - 음수를 입력한 경우 예외를 발생시킨다. 예) (-2,4,-3)
  - 쉼표(,) 또는 콜론(:) 외의 문자 사용 시 예외를 발생시킨다.
  - 커스텀 구분자 사용이("//"와 "\n" 사이에 있어야 함) 잘못된 경우 예외를 발생시킨다.
  - 커스텀 구분자는 문자이다. 즉 커스텀 구분자의 길이가 1이 아닌 경우 예외를 발생시킨다.
  - 커스텀 구분자가 숫자인 경우 예외를 발생시킨다.
- 반환 : 구분자를 기준으로 분리된 숫자들을 리스트로 반환한다.
### 2.3 덧셈 결과 계산 기능
- 반환된 리스트의 숫자들을 모두 더한다.
- 리스트가 공백인 경우 총합을 0으로 계산한다.
### 2.4 결과 출력 기능
- 입력된 숫자들의 총합을 보여주는 문구를 출력한다. (예 : `결과 : 6`)
